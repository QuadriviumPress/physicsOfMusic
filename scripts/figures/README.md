# Figure generation

Figures are generated with matplotlib and written as SVG into
[`../../images/`](../../images/). The rendered SVGs are **committed**, because
the GitHub Pages workflow runs `myst build --html` only — there is no Python
available at build time.

Staff notation is generated separately, by VexFlow; see
[`../render-notation.mjs`](../render-notation.mjs) and
[`../notation_text_to_path.py`](../notation_text_to_path.py). Audio examples and
their companion figures are generated by [`../audio/`](../audio/).

## Regenerating

```bash
python3 -m pip install -r requirements-figures.txt
python3 scripts/figures/brand_assets.py     # social card, favicon, header logos
npm run check:figures                       # regenerate all and diff
```

Each script prints the files it writes. Commit the regenerated SVGs along with
any change to the scripts, so the site and the source stay in step.

The matplotlib version is pinned. Its SVG output — element ids, path rounding,
metadata — changes between versions, so an unpinned regeneration turns every
figure into a diff and `check:figures` into noise.

## Layout

| File | Contents |
|---|---|
| `figstyle.py` | Shared rcParams and palette, `save()`, and the music-specific helpers: `waveform`, `spectrum`, `wave_and_spectrum` (the standard two-panel audio companion), and `cents_ruler` for comparing tunings |
| `brand_assets.py` | Social card, favicon, and the light and dark header logos |

Per-chapter generators are added as `chNN_figures.py` for computed curves,
`chNN_schematics.py` for diagrams, and `chNN_solutions.py` for figures that
appear inside worked solutions.

## Conventions

- **File names are `ch<NN>-<slug>.svg`**, and `ch<NN>-sol-<slug>.svg` for a
  figure that appears inside a worked solution.
- **Use the shared palette.** `BLUE` is the default, `RED` the contrast, and the
  rest of `CYCLE` for a third and fourth series. A figure that invents its own
  colours will not sit beside the others.
- **A spectrum is a line spectrum.** `spectrum()` draws stems, not a filled
  curve: the point of nearly every spectrum in this book is *which* partials are
  present, and a filled curve invites the reader to see energy between them
  where there is none.
- **Label axes in units a non-specialist can read.** This is a course whose
  stated outcome is communicating to that reader; the figures are part of it.
- **Every figure needs `:alt:` in the directive that uses it.**
  `scripts/validate-project.mjs` fails the build without one.
